# Лабораторная работа №2. Виртуальный датчик для контроля обжига

В этой работе я проверил, можно ли оценивать концентрацию продукта по показаниям печи, пока лаборатория обрабатывает пробу. Я совместил замеры с минутной телеметрией, добавил признаки по истории датчиков и сравнил Ridge, случайный лес и градиентный бустинг.

## Запуск

1. Установите Python 3.12 и поместите четыре выданных CSV в папку `data/` рядом с ноутбуком.

   ```text
   data/
     data_train.csv
     target_train.csv
     data_test_small.csv
     target_test_small.csv
   ```

2. Создайте виртуальное окружение и откройте ноутбук.

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   python -m notebook kiln_soft_sensor.ipynb
   ```

   В Windows используйте команду PowerShell `.\.venv\Scripts\Activate.ps1`.

3. Выберите **Run All**, чтобы повторить расчёты. Графики и таблицы уже сохранены в ноутбуке, поэтому результаты можно посмотреть сразу.

## Как читать результаты

В файле лаборатории у каждой пробы есть одна временная метка. Я принял её за время выдачи результата и отнял 12 минут, чтобы оценить момент отбора. В ноутбуке также показано, как меняется ошибка при сдвигах на 0, 10 и 15 минут.

По временной валидации я выбрал бустинг со средним MAE 0,0724. На 318 тестовых пробах его MAE составил 0,0622 в шкале столбца `target`, WAPE - 29,7%. Модель угадала рост или падение в 53,5% двухчасовых пар. Для сравнения, у последнего доступного лабораторного анализа MAE получился 0,0595.

На последнем графике видно, как оценка меняется между пробами. В эти минуты у меня нет лабораторного значения, поэтому метрики рассчитаны только по пробам. По остаткам видно, что ошибки модели связаны во времени, а их разброс меняется в зависимости от уровня оценки.
